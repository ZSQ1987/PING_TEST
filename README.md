# PING Test Tool 2025

一个功能强大的IP网络连接速度测试工具，支持批量测试、IP持久化、持续模式、域名支持等功能。

## 功能特点

- **批量测试**：支持同时测试多个IP地址或域名
- **IP持久化**：自动保存和加载IP地址列表
- **持续模式**：支持持续PING模式（-t参数）
- **域名支持**：支持输入域名进行测试
- **实时输出**：持续模式下提供实时输出窗口
- **详细结果**：显示平均延迟、最小/最大延迟和丢包率
- **界面美观**：专业美观的GUI界面，支持自定义布局
- **本机IP显示**：在状态栏显示本机IP地址

## 技术栈

- Python 3.11+
- PySide6 (GUI框架)
- Subprocess (执行PING命令)
- JSON (数据持久化)
- PyInstaller (打包工具)

## 安装和使用

### 直接使用

1. 下载打包好的可执行文件 `PINGTEST.exe`
2. 双击运行即可

### 从源码运行

1. 克隆或下载本项目
2. 安装依赖：`pip install PySide6 Pillow`
3. 运行：`python ping_test_2025.py`

### 打包

1. 安装打包工具：`pip install pyinstaller`
2. 运行打包脚本：`.acking.ps1`
3. 打包后的可执行文件会在 `dist` 目录中

## 使用说明

1. **输入IP地址**：在左侧IP输入框中输入要测试的IP地址或域名，每行一个
2. **配置参数**：
   - PING次数：设置每个IP的测试次数
   - 持续PING：启用持续PING模式
   - 结果展示布局：设置结果展示的行数和列数
   - 界面大小：调整窗口大小
3. **开始测试**：点击"PING测试"按钮开始测试
4. **查看结果**：测试结果会显示在下方的网格中，包括IP地址、测试状态、平均延迟、最小/最大延迟和丢包率
5. **停止测试**：点击"停止测试"按钮停止测试
6. **清空IP**：点击"清空IP"按钮清空当前输入的IP地址
7. **配置**：点击"配置"按钮打开配置对话框
8. **帮助**：点击"帮助"按钮查看使用说明

## 注意事项

- 测试结果受网络环境影响，建议在稳定网络环境下测试
- 测试大量IP时可能会占用较多系统资源，请合理设置测试数量
- 某些防火墙设置可能会影响PING测试结果
- 本工具仅供学习和交流使用
